# Purrmiere Packs

The pack library for the Purrmiere video editor: asset packs, the 1999 old web pack, shader effects, voice
effects, text styles and text animations that are kept out of the main install.

Purrmiere reads `catalog.json` from this repository and shows every pack in its pack library. You download a
whole pack or just one item; dragging an item into a project downloads only that item, and anything already on
your PC is used straight from your packs folder without downloading it again.

This repository is for Ava and a friend. Some packs hold images made by other people or companies (for example the
MSN Messenger emoticons); they are here for personal use only.
